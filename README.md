# cs2configs
My personal config files for counter-strike 2
<ul>
<li> Config files have to be stored in: <code>"...\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg"</code></li>
<li> Video config has to be stored in: <code>"...\Steam\userdata\YOUR_STEAM32ID_HERE\730\local\cfg</code></li>
  <ul>
    <li> To find your STEAM32 ID, use a site like <a href="https://steamid.xyz/">steamid.xyz</a> , enter your Steam profile URL and copy the STEAM32 ID </li>
  </ul>
</ul>

## Description of files:

### :star2: autoexec.cfg :
My personal playing config including:
- Custom Viewmodel, Sensitivity & Crosshair
- Custom Keybinds
##

### :star2: cs2_video.txt :
My video settings including:
- 4:3 Setup
- Graphic settings for maximum performance and vision clarity
##

### :star2: practice.cfg :
Mostly for testing and practicing stuff in private games including:
- Static bots 
- Infinite ammo, money, buytime & round-length
- Buying anywhere
- Grenade preview window
##

### :star2: bhop.cfg :
Simple config to enable auto-bunnyhopping in private games.
- Disable by using "bhop_disable.cfg"
##

### :star2: reset_cvars.cfg :
Resets all custom cvars and restores normal gameplay.
##

### :star2: gamemodes :
A collection of custom gamemodes.
##

### :star2: viewmodels & crosshairs :
Some viewmodels and crosshairs I use for playing.
- Switchable via arrow keys (set in autoexec.cfg)
##
